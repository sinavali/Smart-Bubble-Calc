# Mobile Client (حباب سنج و نبض بازار)

Cross-platform mobile application built with Flutter/Dart for Iranian users, targeting Cafe Bazaar, Myket, and Google Play.

---

## Key Features

- **Anti-AI-Slop Minimalist UI:** Flat, Swiss-inspired financial terminal aesthetic using neutral tones and tabular typography.
- **10 Core Assets Live Ticker:** Real-time updates for Emami, Quarter, and Half coins, 18k gold, USD, Tether, Dirham, and Bitcoin.
- **On-Device Neural Network (NN):** Runs an on-device micro-MLP model inside a Dart Isolate to evaluate bubble regimes and provide personalized DCA entry scoring without cloud compute cost.
- **Jewelry Calculator (ماشین حساب طلافروشی):** Legal calculation of 18k gold purchases according to Iranian tax laws (9% VAT applies strictly to Labor + Profit).
- **Yektanet Ad Monetization:** Integrated with Yektanet In-App SDK (banners, 3:4 native cards, and rewarded video unlocks).
